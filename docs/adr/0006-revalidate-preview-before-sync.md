# Revalidate preview before synchronization

A confirmation authorizes the Source commit and file or symbolic-link changes shown in its preview. For local entries that would be replaced or removed, the preview records a SHA-256 fingerprint of the file content or link target. RepoMirror obtains the Source again when synchronization starts and rejects the item if its commit, change list, or affected local content differs, rather than applying an unseen update. Symbolic links used as Destination parent paths and file-versus-directory conflicts are rejected before preview or writes. Links inside a Destination are copied or unlinked as links without following their targets.
